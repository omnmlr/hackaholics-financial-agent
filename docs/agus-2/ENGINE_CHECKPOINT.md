# Central agent engine — 9 November 2026

Branch: `dev/agus2-agent-engine-20261109`, isolated from preserved `4e378f4` and main. No deployment/merge.

The previous conversation entry point required financial-demo access before any reasoning. Its financial loop mixed narration rules, savings interpretation and payment handoffs into general conversation; several tools terminated the turn, and personal tools suppressed the model's final answer. Personal results exposed acknowledgement text rather than structured facts. There was no durable general execution ledger, and a repeated call could abort otherwise useful work.

The existing `native-gemini` + `AGUS_WORKSPACE_ENABLED=true` configuration now uses [the general coordinator](../../src/lib/personal-agent/engine.ts) through the conversation composition root. `FINANCIAL_DEMO_ENABLED` is optional for general work. Configure `AI_PROVIDER=gemini`, `AI_MODEL=gemini-3.5-flash-lite` and a legitimate authorized key through environment settings. At ₦0, confirm free-tier entitlement before actual requests. No secret is committed here.

- Model-selected tool composition (including focused financial subquestions), optional user-visible plans, schema feedback/correction, structured results and a natural final answer. No phrase-based general intent router, mandatory account selection or command grammar.
- Ordinary reasoning/planning requires no approval. Existing memory/reminder/devnet proposals retain their human boundaries. The financial specialist keeps current consent, ownership, source checks, deterministic calculations and source presentations. The coordinator retains the specialist's financial paragraphs and filters conflicting free-form amounts/outcome claims rather than replacing source-bound narration; its read-only mode is enforced at dispatch, not merely by hiding a tool name.
- Owner-scoped development run journal: goal, plan, actual tool steps, uncertainties and final outcome. Pauses/cancellation cannot overwrite committed steps or be overwritten by a late completion. No hidden chain-of-thought is exposed or checkpointed.
- Stable server-derived operation keys for memory/reminder/unsigned-devnet preparation, cached completed calls, interrupted-effect handling and process-restart recovery. Uncertain non-idempotent work requires inspection; it is never blindly retried. Forgotten memory gets a content-free tombstone so an old operation key cannot recreate it.
- Fresh owner context across interactions. Financial results are not restored as current authority across invocations; cached financial disclosure rechecks authorization/source versions. Normal links/numbers survive general context redaction; credential text, authenticated URL material and secret fields do not enter model-visible context.
- Bounded execution: 12 total provider calls (including financial-specialist calls), 16 tool attempts and 75 seconds per invocation, with durable explicit resumption. One transient 5xx retry and one narration-repair opportunity; completed writes are not repeated. No background inference service or unlimited autonomy is claimed.

API: `POST /api/conversation` accepts optional UUID `requestId` for idempotent replay. `GET /api/agent-runs[?id=UUID|conversationId=ID]` returns owner-scoped status/plan/steps, not raw model internals. `POST /api/agent-runs` accepts `{action:"pause"|"cancel"|"resume",id,version,acknowledged:true}`; resume is for paused/interrupted runs and reuses the original authenticated conversation route. A completed response is not proof of an external action. `waiting_user` denotes pending proposals/inputs; approval activates the separate responsibility, and a subsequent conversation retrieves that fresh state. Automatic continuation of a dependent general run after approval is not implemented.

Banking remains provider-neutral and blocked on authorized institutional access: existing Nigerian personal SOURCE accounts, balance/history and bank-controlled beneficiary payments, with the existing launch coverage/markup requirements unchanged. No merchant-funded payment route or new wallet is presented as that integration.
