## Runtime

- Set `FIRECRAWL_API_KEY` on the backend. In Codex Cloud, this is a domain-scoped HTTP secret. Node 24 can use the managed proxy with `NODE_USE_ENV_PROXY=1`. Inject the production Firecrawl credential through the hosted runtime secret configuration.
- Configure `AGUS_CRYPTO_RESEARCH_DAILY` and `AGUS_CRYPTO_RESEARCH_GLOBAL_DAILY` to bound provider requests. Defaults are three cache misses per user and ten cache misses across all users per UTC day. Attempts count against the caps even if Firecrawl fails. A limit of `0` disables new research requests. The shared PostgreSQL usage table retains reservations across restarts.
- Public link research looks up indexed HTTPS pages and requires an exact canonical result. If the index lacks the page, AGUS reports unavailable evidence. AGUS fetches only the fixed Firecrawl API endpoint and does not follow redirects. It sends only minimized public topics or a public hostname and short page terms, with no wallet context.
- Provider results use a bounded in-memory cache. Citations distinguish retrieval time from an available publication date. Gemini receives only bounded excerpts, has no executable tools in the synthesis step and must return a source ID and a matching quote for each claim. AGUS renders claim citations from validated source records. For wallet state, settlement and exact balances, the assistant uses its scoped blockchain tools.
