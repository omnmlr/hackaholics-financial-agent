## 2. Deliverables Inventory

The following files have been created strictly within `deploy/crypto/aws/` and `docs/agus-crypto/engineering/evidence/`:

1. `deploy/crypto/aws/docker-compose.yml`:
   - Isolated multi-container definition with services `caddy`, `api`, and `worker`.
   - `caddy` exposes public ports `80` and `443` (TCP & UDP/HTTP3).
   - `api` exposes internal port `3000` on bridge network `crypto-internal` (not published to host).
   - `worker` exposes no ports (unexposed daemon).
   - Bounded JSON logging (`max-size: 20m`, `max-file: 5`) and `unless-stopped` restart policy.
   - Resource limits: `1024M` for API, `512M` for Worker.
2. `deploy/crypto/aws/Caddyfile`:
   - Automatic TLS certificate management via Let's Encrypt / ZeroSSL.
   - Security headers: HSTS, X-Content-Type-Options: nosniff, X-Frame-Options: DENY, Referrer-Policy: strict-origin-when-cross-origin.
   - 10MB request body limit.
   - Active health check forwarding to `http://api:3000/api/v1/ready`.
3. `deploy/crypto/aws/setup-host.sh`:
   - Idempotent host bootstrap script for Ubuntu 24.04 LTS / Debian 12 (x86_64).
   - Enforces IMDSv2 token acquisition.
   - Installs official Docker CE and Docker Compose plugin.
   - Configures `/etc/docker/daemon.json` with bounded logging.
   - Creates directory `/etc/agus` (mode `0700`) and placeholder `/etc/agus/crypto.env` (mode `0600`).
4. `deploy/crypto/aws/preflight-check.sh`:
   - Host-side preflight verification script (`set -euo pipefail`).
   - Verifies Docker daemon, compose plugin, host memory (>= 1.8 GiB), root disk space (>= 5 GB).
   - Validates `/etc/agus/crypto.env` exists with strict permissions (`0600` or `0400`).
   - Performs static validation of required variables (`DATABASE_URL`, `BETTER_AUTH_SECRET`, `AGUS_ENCRYPTION_KEYS`, `APP_ORIGIN`, `BETTER_AUTH_URL`, `AGUS_ENVIRONMENT=devnet`).
   - Asserts absence of forbidden variables (`MIGRATION_DATABASE_URL`, `PAYSTACK_SECRET_KEY`, `LIVE_TRANSFERS_ENABLED`).
   - Checks port availability for ports 80 and 443.
5. `deploy/crypto/aws/rollback.sh`:
   - Safe container teardown (`docker compose down --remove-orphans`).
   - Optional `--purge-volumes` flag for clearing Caddy state.
   - Preserves `/etc/agus/crypto.env` to prevent accidental credential loss.
6. `deploy/crypto/aws/env.production.example`:
   - Complete runtime environment template with zero hardcoded real secrets.
   - Explicit warnings against `MIGRATION_DATABASE_URL` and `PAYSTACK_SECRET_KEY`.
7. `deploy/crypto/aws/README.md`:
   - Comprehensive operational runbook, architecture diagram, sizing analysis (`t3.small` standard CPU credit mode), and official rate schedule.
8. `deploy/crypto/aws/vitest.config.ts`:
   - Isolated Vitest configuration targeting `deploy/crypto/aws/tests/**/*.test.ts`.
9. `deploy/crypto/aws/tests/preflight.test.ts`:
   - Automated offline fail-closed test harness verifying 34 test cases across all 5 failure categories.
