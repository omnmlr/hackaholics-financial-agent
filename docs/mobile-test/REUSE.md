# Main-branch reuse audit

Reviewed remote `main` at `1b56459d187594b2f83e0e35cc2cf3f10187e894`, including the deploy tree, API routes, mobile workspace, migrations, contracts, tests and prior release evidence. The older supplied `work` checkout at `b1862ef` is a different baseline. No historical Bank data, configured live database or permanent signing keys were accessed. REA was unavailable on PATH. Direct source and execution evidence were used.

| Area | Main implementation | Reuse decision |
| --- | --- | --- |
| AWS and Neon | `deploy/crypto/{aws,ec2}` Compose, Caddy, preflight and rollback. `src/server/sql.ts` PostgreSQL pool and transactions, `src/server/migrations.ts` migrations, existing runtime grants. | **Adapt.** Use the role separation, transaction wrapper and deployment pattern with a new schema/database and separate test worker. Current live AWS/Neon access was not needed. The local prototype stores reports on disk. |
| Google and email OTP | `src/server/{auth,auth-schema,email-otp,mobile-google,identity-email}.ts`, Better Auth Expo integration and hosted auth tests. | **Reuse unchanged** behind a hosted AGUS API, after provisioning a separate identity namespace or intentionally retaining the AGUS account boundary. Provider and agent tokens require separate scopes. Local MCP inherits operator access. |
| Gemini multimodal | `src/server/crypto/{assistant,assistant-image,research-summary}.ts`, bounded media validation, usage budgets, grounded evidence. | **Adapt if requested.** Pass minimized test evidence to agent clients first. Redaction and evidence references should persist if adding optional visual diagnosis. A model cannot award a pass. |
| Firecrawl | `src/server/crypto/research.ts` bounded public research, normalization, source provenance and fixed endpoint. | **Obsolete for core runner.** It can support public documentation lookup if later requested. Agent-supplied APK metadata or private logs must stay outside the research pipeline. |
| ElevenLabs | `src/server/crypto/{voice,voice-audio}.ts` transcription/TTS integration, separate budgets and credentials. | **Obsolete for this pivot.** Preserve financial app usage. |
| Wallets and signing | `apps/mobile/src/{crypto-signer,crypto-device-state,crypto-wallet-policy,wallet}.ts`, scoped MWA intent plugin, ownership challenge, exact review, secure storage and restart markers. | **Adapt for testing interface.** Maintain APK as target. | Verification and reconciliation | `src/lib/solana/{rpc,acceptance,assets,classic-spl}.ts`, `src/server/crypto/{rpc,execution,ledger,activity}.ts`, separate reconciliation and replay tests. | **Reuse unchanged** for pinned Devnet RPC and constants. **Adapt** for generic run-context assertions. | Payment requests and escrow | `src/server/{request-chain,requests,p2p}.ts`, `src/server/crypto/requests.ts`, `src/server/escrow`, `escrow` Anchor and bank tests. | **Adapt later** for exact mint, reference and reconciliation. | Scoped spending | Crypto Pocket Zod schema and capability flags in `packages/contracts/src/crypto.ts`. The baseline has no enabled general-purpose job spending service. | **Requires repair or new implementation** if a managed marketplace is approved. Use explicit per-job human authorization first. Do not inherit standing permission from prototype paths or other branches. |
| Workers and notifications | `src/server/jobs.ts` durable queue, `scripts/platform-worker.ts`, `src/server/observability.ts` and Crypto alerts, `apps/mobile/src/notifications.ts`. | **Adapt.** Reuse job claim/idempotency and event patterns. | Native Android and signing | `apps/mobile` Expo app, approved identity, native config plugin, SecureStore, EAS configuration, signed APK workflow and Android verifier in `scripts/android`. | **Reuse release tooling and identity controls** for future compatible Android shell work with Chisom. | Typed contracts/client | `packages/{contracts,api-client}`, generated OpenAPI, Zod validators and fixtures, `scripts/generate-openapi.mjs`. | **Adapt contract generation** for a future additive `/api/v1/mobile-test` namespace. Existing generated files are preserved. The prototype exposes the CLI/MCP contract independently. |
| Prior Paystack/Bank and agent UI | `src/lib/{payments,paystack,financial-agent}` and existing Next.js surfaces. | **Obsolete for pivot.** Maintain as existing product and regression target. |
